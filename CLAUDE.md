# kikocredit.com — упатство за Claude (и за луѓе)

Портал за споредба на потрошувачки кредити од **банки, штедилници и финансиски друштва** во
Северна Македонија. Сопственик: Pece (p.dimitrovski@gmail.com). Јазик: македонски.

## Моделот (од 20.09.2026)
- Корисникот внесува **износ + месечна рата** и добива: број на рати, камата (СВТ), вкупна
  камата, вкупно за враќање — за секој давател што го покрива износот и рокот.
- Копчето **„Аплицирај кај X"** е надворешен линк (`applyUrl`) кон страницата на институцијата.
  KikoCredit **не собира лични податоци** и **не посредува** — тоа е свесна правна одлука
  (кредитен посредник по закон бара нотарско овластување од давателот).
- Се брои само **анонимен клик** (институција, износ, рата, рати, СВТ, уред) во Postgres —
  тоа е базата за идни преговори со давателите („колку клиенти ви носиме").

## Што НЕ смее да се менува без експлицитно барање
- Изгледот „Кико": лисица 🦊, виолетов градиент `#667eea → #764ba2`, бели картички со
  радиус 24px, чекори Износ и рата → Понуди. Клиентскиот тек во `src/App.jsx` треба да
  изгледа исто по секоја промена.
- Логиката во `calculateLoan()` (сортирање по најнизок вкупен трошок).
- **Никаква форма за лични податоци** на клиентскиот дел. Ако некогаш се враќа — прво адвокат.
- Емоџи-ознаките наместо вистински логоа (логоата се заштитни знаци).

## Јавни страници за пребарувачи (од 18.10.2026)
Сè се генерира од `src/institutions.js` при секој build — не се уредуваат рачно:
| Адреса | Содржина |
|---|---|
| `/` | Калкулаторот, пред-генериран (React → HTML, па `hydrateRoot`) + „Пред да земеш кредит“ (водичи од `src/featuredGuides.js`) + листа „Кого споредуваме" |
| `/krediti/` | Сите активни даватели во табели по СВТ + чести прашања (FAQPage) |
| `/krediti/banki/`, `/krediti/finansiski-drustva/` | Табела за групата |
| `/krediti/<slug>/` | Еден давател: износ, рок, СВТ, `notes`, пример пресметка, линкови |
| `/vodici/` | Листа на водичи |
| `/vodici/brz-kredit/`, `/vodici/shto-e-svt/`, `/vodici/banka-ili-finansisko-drustvo/` | Водичи (Article + FAQPage), со извори и пример пресметки |
| `/sitemap.xml`, `/llms.txt` | Генерирани; `robots.txt` е во `public/` |

Правила:
- `slug` е дел од адресата — **никогаш не се менува** (Google веќе ја знае адресата).
- `notes` се прикажува **јавно** на страницата на давателот → пишувај за корисници. Работни
  забелешки („рачна проверка" и сл.) одат во `internalNote`, кое не се прикажува никаде.
- Неактивен давател нема страница; build **паѓа** ако неговото име или адреса се појави во
  генерираните фајлови (заштита за Тиго Фајнанс и сл.).
- Пример пресметка се прикажува само ако давателот нема свој репрезентативен пример во `notes`.
- Водичите: секое законско тврдење има член и извор; без имиња на давателите во примерите.
  Законската граница на СВТ = 5 × законска казнена камата (член 20-а) и се менува на 1 јануари
  и 1 јули — тогаш ажурирај `PENALTY_RATE` во `scripts/guides.mjs` од објавата на НБРМ
  (build-от предупредува кога датумот `to` ќе помине).
- Имињата се подредуваат без `localeCompare` — прелистувачот и Node мора да дадат ист
  редослед, инаку пред-генерираниот HTML не се совпаѓа со React (hydration грешка).
- Во клиентскиот дел не користи `window`/`document` при првото цртање (само во `useEffect`) —
  почетната се црта и на сервер при build.

## Правила за податоците
- `svt` се менува САМО ако е прочитана од сајтот на институцијата (репрезентативен пример или
  тарифник); тогаш `svtVerified: true`. Ако не е објавена: за банки се користи номиналната
  стапка, за друштва последната позната вредност — со `svtVerified: false` и објаснување во
  `notes`. Сајтот тогаш прикажува `*` и забелешка, а таква понуда **не добива „Најповолно"**.
- Ниедна `svt` не смее да е > `SVT_LEGAL_MAX` (60 %).
- `applyUrl` секогаш води кон страницата на институцијата (апликација, калкулатор со форма или
  страница на производот) — никогаш кон трета страна.
- Давател што не постои / е во ликвидација / чиј домен пренасочува / **писмено побарал да не
  се прикажува** → `active: false` + објаснување во `notes`. Не бриши записи (id се користи во
  статистиката). Тиго Фајнанс е деактивиран на негово барање (14.09.2026).
- Емоџи-„логоата" не смеат да личат на вистинските знаци на институциите.

## Постапка: неделна проверка на условите (понеделник)
1. За секој активен запис отвори го `source` (и тарифник/репрезентативен пример) и спореди
   `minAmount`, `maxAmount`, `minMonths`, `maxMonths`, `svt`, `interestRate`, `applyUrl`, `website`.
2. Провери дека `applyUrl` сè уште отвора страница на институцијата (не 404, не пренасочување
   кон друг домен).
3. Примени ги правилата погоре; ажурирај `verifiedAt` за секој проверен запис и `DATA_UPDATED` /
   `DATA_UPDATED_LABEL` на врвот.
4. `npm run check:data && npm run build` мора да поминат. Ако build-от предупреди за
   `PENALTY_RATE`, ажурирај ја (нова референтна стапка на НБРМ + 8 п.п.) во истиот PR.
5. Ако има промени → Pull Request со табела „старо → ново" по давател и линкови до изворите.
   **Не спојувај без потврда од сопственикот.** Ако нема промени → само јави „нема промени".

## Постапка: неделен водич (четврток нацрт → недела објава)
Еден нов водич неделно на `/vodici/<slug>/` + споделување на Facebook и Instagram.
**Ништо не оди на сајтот ни на мрежите без „одобрени“ од Pece.**

**Четврток — нацрт** (закажана задача „KikoCredit — нацрт на неделен водич“):
1. Тема: првата од `scripts/guide-topics.json` чиј `slug` го нема во `GUIDES` и нема отворен PR
   (гранки `vodic/*`).
2. Истражи: секое законско тврдење → член + официјален извор (закон, НБРМ, Министерство за
   финансии); секое тврдење за давател → `institutions.js` или неговата официјална страница.
   Што не може да се потврди — не се пишува.
3. Напиши го водичот како нов објект во `scripts/guides.mjs` (ист облик како постоечките:
   `slug, icon, short, title, h1, description, teaser, lead, body, faq, sources`) и додај го во
   `GUIDES`. Правила:
   - македонски, тон на „ти“, без притисок за земање кредит и без ветувања („сигурно одобрување“);
   - бројките за давателите се пресметуваат од `institutions.js` во кодот (не рачно впишани);
   - примерите се илустративни, без имиња на даватели; имиња само во табели генерирани од податоците;
   - табели со `class="fit"`; износи на крај на реченица со `den()` (не „ден..“);
   - 3–5 чести прашања; извори со линк; `title` до ~65 знаци, `description` до ~160.
4. `npm run check:data && npm run build`; провери на 360 px без хоризонтален скрол
   (Chromium: `/opt/pw-browsers/chromium`), сите внатрешни линкови 200.
5. Гранка `vodic/<ГГГГ-ММ-ДД>-<slug>` → PR во main „Водич: <наслов>“. **Не спојувај.**
6. На гранката `social`: слика со `tools/make_guide_image.py` → `posts/<недела>-vodic-<slug>.jpg`;
   ставка во `posts/vodici.json` со `approved: false`, `published: false`, `pr`, `url`
   (https://kikocredit.com/vodici/<slug>/), `alt`, `caption` (Facebook/Instagram: 2–4 кратки
   пасуси, адресата на водичот, „линкот е во био“ за Instagram, 3–5 хаштагови).
7. Прати му на Pece: слика од водичот на телефон (≈420 px), сликата за мрежите и описот.
   Ако одговори „одобрени“ → ознака `odobreno` на PR-от и `approved: true` во `vodici.json`.
   Ако бара измени → измени на истата гранка, повторно build и прати.

**Недела попладне — објава** (закажана задача „KikoCredit — објава на неделниот водич“):
1. Отворен PR од `vodic/*` со ознака `odobreno` и ставка во `vodici.json` со `approved: true`,
   `published: false`. Ако нема → „нема одобрен водич оваа недела“, ништо не објавувај.
2. Спој го PR-от (squash); почекај Vercel; страницата мора да врати 200 со насловот на водичот.
3. Facebook и Instagram преку Zapier (како задачата за објави, со заштита од двојно објавување).
4. `published: true` во `vodici.json`.

## Статистика — безбедносни правила
- Лозинката НИКОГАШ не се проверува во прелистувачот; панелот се отвора само откако серверот
  вратил 200 на `GET /api/clicks`.
- Лозинката се праќа base64-кодирана (`Bearer b64:…`) — HTTP заглавијата не трпат кирилица.
- Во `clicks` нема лични податоци (нема име, телефон, IP). Ако некој предложи да се додадат —
  тоа е промена на правната положба на сајтот; прво сопственик + адвокат.
